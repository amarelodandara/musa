# AGENTS.md

O projeto é todo em português (PT-BR): site, conteúdo, glossário, ADRs e documentação. Identificadores de código seguem o mesmo padrão.

## Agent skills

### Issue tracker

Issues ficam no GitHub Issues de `amarelodandara/musa`, gerenciadas pelo `gh`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Vocabulário padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Contexto único: um `GLOSSARY.md` e `docs/adr/` na raiz, criados conforme a necessidade. Ver `docs/agents/domain.md`.
