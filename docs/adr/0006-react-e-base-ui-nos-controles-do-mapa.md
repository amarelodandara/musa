# Os controles do mapa usam Base UI, numa ilha de React

O ADR 0005 descartou o React por ser pesado demais para um site estático. Revemos isso para uma parte só: os controles do Mapa da Visita (barra lateral do guia, seletor de modo, setas das Etapas, filtro por Função e o painel de detalhe) são componentes do Base UI, que só existe para React, montados numa única ilha (`client:load`). A grade do mapa, o resto do site e os PDFs continuam em Astro, sem React. O motivo é acessibilidade sem retrabalho: foco, teclado, leitores de tela e camadas sobrepostas ficam por conta de uma biblioteca feita para isso, em vez de código nosso. A contrapartida é o peso do React na página do mapa, que já era a única com JavaScript de verdade. A ilha conversa com `src/scripts/mapa.ts` por eventos (`musa-mapa:estado`, `musa-mapa:detalhe`) e pela API `window.musaMapa`; quem desenha a grade continua sendo o `mapa.ts`.
