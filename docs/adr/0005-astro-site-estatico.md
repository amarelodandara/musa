# O site é refeito em Astro, gerado como estático

O protótipo era HTML solto, com scripts que se comunicavam pelo `window` e o cabeçalho copiado em cada página. Para a versão final, o site passa a ser um projeto Astro com saída estática: cabeçalho, rodapé e as peças do mapa viram componentes, o conteúdo vem do arquivo de dados gerado a partir da planilha (ADR 0002), e a página do mapa e a página de impressão (ADR 0004) compartilham os mesmos componentes. Só o mapa interativo leva JavaScript no navegador. Descartamos seguir com HTML puro (duplicação e muita manipulação de DOM à mão) e Next.js/React (pesado demais para um site estático sem backend). Tailwind v4, a marca, a animação de abertura e o avatar são reaproveitados. O projeto no Vercel passa a ser ligado ao repositório do GitHub.
